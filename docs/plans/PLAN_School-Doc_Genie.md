## **📋 개요**

### **기능 설명**
School-Doc Genie는 학교 행정 공문(HWP, XLS)을 보안 우려 없이 AI로 분석하고 아카이빙하는 시스템입니다. 브라우저 단에서 개인정보를 비식별화하며, Gemini 3.0 Flash 모델을 사용하여 표 구조를 분석하고 요약합니다.

### **성공 기준**
* [ ] 브라우저 네트워크 탭 확인 시, 비식별화된 데이터만 전송됨을 확인
* [ ] HWP/XLS 파일 내 표 구조가 Markdown Table로 정확히 변환됨
* [ ] Gemini 3 Flash API 연동 및 Context Caching 적용 확인
* [ ] Supabase Vector Search를 통해 연관 공문(유사도 0.8 이상) 추천

### **사용자 임팩트**
선생님들이 개인정보 유출 걱정 없이 복잡한 공문을 3초 안에 요약받고, 과거 내역을 즉시 찾아 업무 시간을 단축할 수 있습니다.

| **Supabase (pgvector)** | 단일 스택으로 데이터 및 벡터 관리 | 대규모 검색 시 전용 벡터 DB보다 튜닝 필요성 |
